# FL Studio preset import (2026-11-25)
Choose Chorus or Flangus, open Settings, select Import FL preset / raw settings, and open an .fst. The importer accepts verified FL Studio 25.1 FLhd/FLdt event envelopes, format 0x30 individual effect or 0x40 mixer track. An actual mixer file must contain one uniquely named matching native effect; unrelated slots are ignored, and multiple instances, invalid lengths/ranges/versions or mismatched names are rejected without changing current settings. Imported state covers all native raw controls, not mixer slot gain, slot bypass, routing, other effects, or automation. No FLP import, no FST export, no guarantee for other FL versions. Existing .bin and .sflg import/export preserved. No DSP or plugin ID changes.

Evidence: actual owner-supplied mixer presets from three recovered archives, seven .fst files; 3 valid Chorus states, 5 valid Flangus states. Independent FL Studio 25.1 event scan also confirmed two single-effect Delay 2/3 FST envelopes (wrong effect rejected); standalone Chorus/Flangus export testing remains open. Local GCC and Clang with warnings-as-errors, Clang ASan/UBSan, 20,000 random buffers plus per-byte mutations and truncation checks passed. No private preset, raw user parameter records, project or audio included in repository. The tests use generated public-contract payloads and optional CLI arguments for local private testing.

Fruity Flanger: a named 52-byte versioned payload was found in private Wobbly mixer state and the corresponding project. This is state-layout evidence, not proof of parameter meanings or original DSP. Existing Skell StackedFlanger research is an approximation, not Fruity Flanger DSP. No native replacement or guessed state mapping until actual source / parameter contract and reference validation are available. Current owner-approved Flanger and Orbit R4 remain unchanged. Request native source if available. Prior build 9d27574 CI succeeded; new build and host import UI validation pending.

## FL 26.1.6 standalone regression (November 26)
Three owner-supplied single-effect FSTs (242/260/260 bytes) exposed a parser defect: the observed event 0xAC has three bytes 01 01 00 before C0, rather than the generic four-byte event rule. The old parser returned missing for all three. A narrowly version/header/signature-gated exception restores exact decode, without changing older mixer event handling. Added FL Chorus Default (index 16), FL Low Enhance (17), FL Flangus Default (18). Native defaults exactly match the two supplied FL default payloads; Low Enhance is distinct. Existing 0–15 factory records and all parameter IDs unchanged. Tests cover generated new-format envelopes and host recall of all three. No original FST files committed. Direct UI import in FL Studio remains a target-host test.
