# Native Flangus controls — draft, not release verified
Build private owner v2 with -DSKELLY_FLANGUS_SOURCE_DIR=/path/SkellyFlangus -DSKELLY_FLANGUS_SAMPLE_CLOCK_RAMP=ON. Old package and ramp remain available with the flag off. Native is exclusive when its opt-in is set and mode=6. Other modes use legacy processing. Old raw-enabled trial states migrate focus to Flangus. No published legacy ID or factory identity changed. Existing appended IDs skellyRawOrder/Depth/Speed/Delay/Spread/Cross/Dry/Wet and skellyRawFlangusEnabled are retained. Faders bind native IDs only in native mode. Exact entry and file IO are message-thread operations. Validated settings are separate host gestures, not an atomic audio-thread transaction.

Raw v0: 32 bytes, eight signed little-endian int32 in Order, Depth, Speed, Delay, Spread, Cross, Dry, Wet order. SFLG v1: ASCII SFLG, little-endian u16 version 1, u16 payload size 32, same 32-byte payload. Full FST containers not supported. Codec tests cover 3,088 integer values in both formats, signed bytes and invalid input.

Private v2 optional sample-clock slew: Linux GCC/Clang, synthetic stereo, five rates 32–192kHz, eight blocks 32–4096, 18 voices, zero difference across tested blocks and frozen original vs new. This is an intentional automation change, not FL Studio equivalence. Private source stays private. Native JUCE build, real editor screenshots, pluginval, real audio A/B, host state recall and MSVC parity remain unverified. Do not distribute this draft as verified.
