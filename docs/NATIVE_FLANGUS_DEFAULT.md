# Native-only Flangus / Orbit Revision 4
The old synthetic Flangus DSP implementation has been removed from EngineBank. Slot 6 retains its identity but is a marker for the required native full-mix engine. The normal VST3 CMake target requires native source. The single existing CI workflow consumes either checked-in authorized source or repository secret SKELL_FLANGUS_SOURCE_B64 (a base64 ZIP with Flangus.cpp, SkellFlangusAdapter.h, core/FlangusFastDist.h). No separate private build, no old engine fallback. Do not publish source without approval of rights holders. Missing secret fails explicitly instead of producing a mislabeled VST3.
Orbit always uses measured Revision 4; Enhanced Motion remains a separate option for Chorus, Flanger and Dimension. Native Flangus is not affected by that option.
The prior raw-enable ID is retained but ignored for routing. Old nonnative sessions migrate their eight normalized settings into native raw units, with no claim of acoustic equivalence. Earlier native trial sessions retain exact signed raw settings and exclusive routing. Legacy mode/morph weight still contributes native full-mix output, and layers replace a share of rack dry instead of double-mixing. At unsupported rates the native layer passes through, not the removed algorithm. Factory names and all original mode indexes remain.
Native-source release gates: portable tests including the actual native engine, Windows host smoke, pluginval and real local Quick4. GitHub cannot build the native VST3 until the source secret is configured. Source-less portable tests remain runnable independently.
