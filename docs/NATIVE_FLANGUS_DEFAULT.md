# Native Flangus normal-engine migration (draft)
When native source is installed in Source/NativeFlangus, the ordinary CMake / GitHub build picks it up automatically. No second VST3 identity and no opt-in trial menu. Explicit legacy source override remains compatible. The source is not in the public checkout yet; this draft does not authorize source redistribution. A source-less checkout compiles the compatibility engine, not the new native variant. Use -DSKELLFLANG_REQUIRE_NATIVE=ON to forbid fallback at configure time.

Fresh instances and factory presets set the native flag. Flangus mode 6 binds the existing eight raw integer controls. Flangus Glow / Motion / Jet retain names and positions, with distinct new native starting states. Old sessions missing the native flag restore the old algorithm; old enabled trial states restore their exclusive routing. No automation IDs removed. A legacy session may be converted through the settings menu. Other modes and enhanced Orbit remain unchanged.

Layer stack: native full dry/wet replaces its normalized legacy full-mix contribution rather than being added on top of rack dry. Layer weighting and master output/bypass preserved. Older exclusive trial sessions retain their routing. Non-layer legacy Mode/Morph routing is retained for old sessions; explicitly native focused mode in that path remains exclusive. New factory patches use Layer Stack. Full native source parity, native host and UI validation and FL Studio recall remain release gates.
