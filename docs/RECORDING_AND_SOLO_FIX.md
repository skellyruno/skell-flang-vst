# Recording and effect selection
User listening feedback 2026-11-25: native Chorus and Flanger sound accurate; default single-click stacking unexpected; live vocal monitoring feels laggy; CPU rises with four or more layers; FL Studio reportedly froze during close/switch. No reproduction in FL Studio yet.

Single click now solos the chosen effect immediately. Double-click toggles a layer relative to the previous selection (the first click takes effect immediately and the second restores the original stack with the new toggle; a brief solo transition can occur). Shift-click adds or focuses immediately without that transient. Last layer protected. Saved layer flags and original parameter IDs remain. No new Output knob or attachment; old Output gain still recalls and can be automated by host, new defaults 0 dB. No changes to native Chorus/Flangus source or default raw values, Orbit R4 retained.

Audio callback: settled single-layer fast path; omit generic native placeholder smoothing; cache APVTS atomic parameter pointers; only obtain settings for enabled/ramping layers; don't render a disabled native engine just because its tab is focused when another layer is active. Cache exact unchanged LFO frequency; skip unused legacy sine for full enhanced quality. UI timer repaints only signal meter area; explicit detach controls and cancel owned file dialogs before destruction. Optional WorldLink reconnect wait is interruptible on shutdown (no new network activity). These changes target actual redundant work and teardown risk; no proof yet that they resolve FL Studio-specific freeze.

Direct native impulse probe, input .5 at sample 0: Chorus dry .35 and first wet above 1e-6 at 16.19–16.21 ms, Flangus dry .2520 and first wet .45–.59 ms, 44.1/48/96/192 kHz. Both native effects have immediate dry, not block buffering; deliberate modulation delays can feel like a doubled voice while recording. Shorter Chorus Delay or using Flangus for monitoring avoids much of that sensation; don't change approved sound or misreport PDC. A 64/128-sample interface buffer also helps if interface/DAW monitoring is the source. Full host CPU, shutdown and real local screenshots still release gates.
